# Single Source of Truth

This directory (`/carryout`) contains the foundational documents that define the design, architecture, and business logic of the application. 

**Purpose:**
This collection of documents is designed to be ingested by an AI Agent to perform massive codebase refactoring, UI standardization, and logic implementation. By strictly adhering to these rules, the agent ensures that the application has a "single point of truth."

**How to Use:**
1. Fill in the project-specific details in each of these templates.
2. Provide the finalized directory to the agent with instructions such as: "Read the /carryout directory and apply these standards across the entire codebase."
3. The agent will use these documents as immutable rules for code generation.

**Contents:**
- `01-UX-Dictionary.md`: Universal UI/UX principles.
- `02-Architecture.md`: System design and technology stack.
- `03-Codebase-Structure.md`: File and directory organization.
- `04-Business-Plan.md`: User personas, workflows, and business goals.
- `05-Color-Palette.md`: Design tokens and semantic color definitions.
- `06-Page-Architecture.md`: Layout skeletons and structural guidelines.
